# 样例数据说明

| 文件 | 编码 | 用途 | 埋的坑 |
|---|---|---|---|
| `daily_sales_gb18030.csv` | GB18030 | 主样例：日销与价格 | 声明 utf-8 实际 GB18030、千分位、全角数字、元/箱混用、`-`/`N/A`/`未知` 哨兵、缺日、重复日、末列多余、单价 0、单价 0.99 |
| `daily_sales_utf8bom.csv` | UTF-8 + BOM | BOM 与分段样例 | BOM、引号内含换行、重复表头 |
| `promo_calendar.csv` | UTF-8 | 促销日历 | 版本区间重叠、相邻区间端点相接、活动价 0、待审版本 |
| `control_group.csv` | UTF-8 | 对照组日销 | 含一条单价 `未知` |
| `truncated_tail.csv` | GB18030 | 截断样例 | 末行半行 |
| `header_only.csv` | GB18030 | 空态样例 | 只有表头 |
| `empty.csv` | — | 空态样例 | 0 字节 |

主样例规模：8 个商品×渠道序列 × 45 天，合计 377 条数据记录；促销 4 个（2 个可测算、1 个被活动价阻断、1 个待审）。
